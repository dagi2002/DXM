Pulse design system

The proposed visual language for the DXM Pulse rebuild. It's calm, bilingual, and leads with the answer. Toggle dark mode in the corner, and narrow the window to see the phone layouts.

Color

The brand blue (Abay) stays out of the status hues, so a primary button never reads as "healthy". Saffron (Meskel) marks AI-generated content only. Status colors always come with an icon and a word.

Rules that every screen follows

Answer first

Each page opens with one sentence that states the conclusion. Charts come after it.

One truth per number

Units are typed (ratio vs percent), and every metric has one formatter. A "1820% bounce rate" becomes impossible.

Honest UI

No mock numbers, no fake "LIVE" badges, and no links that point back to "/".

Bilingual by construction

Every component is tested in Amharic. <html lang> follows the UI language. Copy is written in Amharic, not translated word for word.

Phone on mobile data

Designed at 360px first. Budgets: 120 KB of app JS, LCP under 2.5 s on Slow 4G.

Accessible by default

WCAG 2.2 AA. Every chart has a text alternative. axe-core must report zero violations in CI.
