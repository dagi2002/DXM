# ADR-009 — AI: model routing, structured output, budgets

**Status:** Proposed · **Date:** 2026-10-04

## Context
- Prompts are free-form and parsed with regex.
- The cache key includes volatile fields, so nearly every view triggers an LLM call.
- No timeouts, budgets, or plan gates.
- Output is English-only for briefs.
- Untrusted visitor text flows into prompts.

## Decision
- All AI calls go through `packages/ai`. Each one is a **task** with a typed input, a Zod output schema (enforced via tool-use or structured output), a model tier, a timeout (20s), one retry, and a deterministic fallback.
- **Model routing:**
  - **Claude Haiku 4.5** for high-volume tasks (visit recaps, issue explanations).
  - **Claude Sonnet 5.5** for weekly/monthly narratives and fix recommendations, where quality sells.
  - Both are configurable per environment.
- **Prompt caching** for the static system and context parts. Artifacts are cached by a hash of *stable* evidence only.
- **Budgets:** usage is metered per org (tokens and cost) and capped per plan. When the cap is hit, the task degrades to the fallback with a visible notice.
- **Amharic is a first-class output language.** A glossary is injected. An eval set of 30+ Amharic outputs is reviewed by a native speaker before launch.
- **Untrusted data:** visitor-derived strings go into delimited `<data>` blocks with an instruction never to follow instructions found in them. Output links are restricted to internal routes.
- **Evals** live in `packages/ai/evals`, with fixtures and rubric checks run in CI on prompt changes.

## Consequences
Predictable cost, consistent shapes, better Amharic, and safe degradation.
